# Политика безопасности

## Поддерживаемые версии

Поддерживается актуальная опубликованная версия чат-бота `Аралтыш` и текущая ветка `main`.

## Как сообщить об уязвимости

Если вы нашли уязвимость, не публикуйте подробности в открытых issue до первичной проверки.

Сообщите автору через GitHub Security Advisory или другой доступный приватный канал связи, указанный в профиле репозитория.

В сообщении укажите:

- версию или commit;
- окружение запуска;
- шаги воспроизведения;
- возможное влияние;
- фрагменты логов без токенов, паролей, chat id, user id и других чувствительных данных.

## Сроки реакции

Ориентировочный срок первичного ответа: 1-3 рабочих дня.

## Секреты и эксплуатационные данные

Не прикладывайте к issue, pull request или логам:

- токены MAX, npm, GitHub, GitVerse, Docker;
- приватные SSH-ключи;
- файлы `.env`;
- резервные копии базы данных;
- chat id, user id и другие эксплуатационные идентификаторы реальных пользователей;
- документы с персональными данными.

Секреты и эксплуатационные настройки должны храниться вне репозитория: в переменных окружения, секретах CI/CD или настройках сервера.
