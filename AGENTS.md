# Аралтыш на Jino
Рабочая ветка сервера — `production-jino` в публичном репозитории yasg1988/sos-max-bot. После проверки завершённых изменений проверь состав коммита и отправь изменения в эту ветку. Публикация релиза из main выполняется отдельно.
Служба araltysh запускает app.py в /opt/araltysh. Статистика и резервное копирование запускаются системными таймерами. Описания служб находятся в ops/systemd. Параметры доступа задаются на сервере через окружение. Секреты, закрытые ключи, реальные конфигурации, адресаты рассылок, журналы обращений и дампы храни вне Git.
