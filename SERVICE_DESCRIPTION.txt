Описание сервиса "Аралтыш"

"Аралтыш" - чат-бот для MAX, который помогает ребенку быстро отправить сигнал о помощи родителям или законным представителям. Сервис работает как семейная тревожная кнопка: ребенок нажимает кнопку помощи, отправляет геолокацию, а привязанные родители получают уведомление с координатами и ссылками на карты.

Основные пользователи

1. Родитель
   - регистрируется в боте;
   - создает одноразовый код для подключения ребенка;
   - подтверждает связь с ребенком;
   - получает тревожные сообщения и геолокацию ребенка;
   - может запросить геолокацию ребенка через бота;
   - управляет подключенными детьми;
   - видит профиль и семейные связи.

2. Ребенок
   - регистрируется в боте;
   - вводит одноразовый код родителя;
   - после подтверждения получает доступ к кнопке "Нужна помощь";
   - может отправить тревогу "Опасность", "Я потерялся" или тестовую тревогу;
   - отправляет геолокацию по запросу родителя или при тревоге;
   - видит список подключенных родителей.

Ключевой функционал

- Семейная привязка через одноразовый код.
- Подтверждение связи родителем перед активацией тревожной кнопки.
- Отправка тревоги с геолокацией родителям.
- Кнопки реакции для родителей: "Принял", "Еду", "Закрыть".
- Уведомление ребенка, если родитель отметил, что едет.
- Запрос геолокации ребенка родителем.
- Возможность ребенка отказаться от отправки геолокации по запросу.
- Управление подключенными детьми и отключение семейной связи.
- Раздел "Помощь" с инструкциями для родителей и детей.
- Раздел "Рекомендации безопасности" с отдельными материалами для ребенка и родителя.
- Раздел "О проекте".
- Профиль пользователя с именем, ролями и семейными связями.

Техническая часть

- Платформа: MAX messenger.
- Backend: FastAPI webhook service.
- Основной webhook: https://sos.yasg.ru/webhook/max
- Health endpoint: https://sos.yasg.ru/health
- Хранение данных: PostgreSQL.
- Основные схемы БД:
  - sos_core - пользователи, состояния, аудит;
  - sos_family - семейные связи, коды, тревоги;
  - sos_org - зарезервированная организационная часть.
- Деплой: Docker/Dokploy.
- Сборка образа: GitHub Actions.

Безопасность и ограничения

- Токены и параметры подключения к базе не хранятся в репозитории.
- MAX_BOT_TOKEN, MAX_WEBHOOK_URL и параметры БД задаются через переменные окружения в Dokploy.
- Геолокация отправляется только после действия пользователя в MAX.
- Родитель получает данные ребенка только после подтвержденной семейной связи.
