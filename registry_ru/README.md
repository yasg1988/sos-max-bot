# Пакет документов для включения ПО "Аралтыш" в реестр российского ПО

Папка содержит рабочий комплект документов для подготовки заявки в единый реестр российских программ для ЭВМ и баз данных.

Правообладатель:

- ИП Якунин Сергей Георгиевич
- ИНН: 121504484728

Программный продукт:

- Наименование: "Аралтыш"
- Тип: серверное прикладное программное обеспечение, чат-бот/webhook-сервис для мессенджера MAX
- Назначение: экстренная семейная связь ребенка с родителями или законными представителями
- Репозиторий разработки: `https://github.com/yasg1988/sos-max-bot`
- Публичные артефакты: npm `araltysh`, Docker Hub `lmserg/araltysh`, GHCR `ghcr.io/yasg1988/sos-max-bot`

## Важно

Этот комплект является проектом документов. Перед подачей рекомендуется:

1. Проверить актуальные требования реестра на дату подачи.
2. Заполнить реквизиты правообладателя полностью.
3. Определить основной российский контур хранения исходного кода и сборки.
4. Провести тестирование на российских ОС и заполнить протоколы.
5. Проверить документы по персональным данным с юристом.

## Состав папки

- `01_карточка_ПО.md` - сведения о ПО для переноса в заявление.
- `02_описание_функциональных_характеристик.md` - назначение и функции.
- `03_инструкция_по_установке.md` - установка и запуск.
- `04_инструкция_администратора.md` - эксплуатация и администрирование.
- `05_инструкция_пользователя.md` - сценарии родителя и ребенка.
- `06_описание_жизненного_цикла.md` - разработка, релизы, сопровождение.
- `07_технические_средства_хранения_и_сборки.md` - контур исходников, сборки и артефактов.
- `08_программа_и_методика_испытаний.md` - план испытаний.
- `09_протокол_совместимости_с_ОС.md` - шаблон протокола тестирования.
- `10_персональные_данные_и_приватность.md` - описание минимизации ПДн.
- `11_согласие_на_обработку_ПДн.md` - проект пользовательского согласия.
- `12_чеклист_готовности.md` - контрольный список перед подачей.
