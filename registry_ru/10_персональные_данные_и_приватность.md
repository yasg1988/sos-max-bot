# Персональные данные и приватность

## Позиция по обработке данных

ПО "Аралтыш" не запрашивает избыточные персональные данные пользователей: паспортные данные, СНИЛС, адрес регистрации, документы, сведения о доходах и иные данные, не требуемые для работы семейной тревожной кнопки.

При этом для работы сервиса обрабатывается минимальный набор данных, который может относиться к персональным данным:

- идентификатор пользователя MAX;
- идентификатор чата MAX;
- отображаемое имя, введенное пользователем;
- роль пользователя;
- семейная связь "родитель-ребенок";
- одноразовые коды привязки;
- тревожные события;
- геолокация, отправленная пользователем через MAX;
- служебные состояния диалога.

## Цели обработки

Данные обрабатываются исключительно для:

- регистрации пользователя в боте;
- создания семейной связи;
- доставки тревожного сигнала родителям;
- передачи геолокации при тревоге или по запросу;
- управления подключенными детьми и родителями;
- обеспечения безопасности и диагностики работы сервиса.

## Принципы

Сервис реализует принципы:

- минимизация данных;
- обработка только для заявленных функций;
- отсутствие публикации данных;
- хранение секретов вне исходного кода;
- передача геолокации только после действия пользователя;
- доступ родителя к данным ребенка только после подтвержденной семейной связи.

## Сроки хранения

Рекомендуемая политика:

- профили пользователей хранятся до удаления пользователем или администратором;
- семейные связи хранятся до отключения связи;
- одноразовые коды хранятся до истечения срока действия;
- тревожные события хранятся в течение срока, необходимого для разбора инцидента и эксплуатации сервиса;
- журналы хранятся в ограниченный срок, определенный оператором.

Точные сроки необходимо утвердить внутренним регламентом оператора.

## Удаление данных

Пользователь может запросить удаление данных через контакт оператора.

После подтверждения запроса удаляются:

- профиль пользователя;
- семейные связи;
- связанные тревожные события, если нет законных оснований для дальнейшего хранения;
- состояния диалога;
- неиспользованные коды.

## Передача третьим лицам

Данные передаются:

- инфраструктуре мессенджера MAX в рамках работы чат-бота;
- провайдеру хостинга/серверной инфраструктуры, если он используется для размещения сервиса;
- иным лицам только в случаях, предусмотренных законом или договором.

## Меры защиты

Рекомендуемые меры:

- HTTPS для webhook;
- хранение токенов и паролей в защищенных переменных окружения;
- ограничение доступа к серверу;
- резервное копирование PostgreSQL;
- журналирование действий администратора;
- регулярное обновление зависимостей и контейнерного образа.
