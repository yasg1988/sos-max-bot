# Правила участия

Спасибо за интерес к проекту `Аралтыш`.

`Аралтыш` — чат-бот в MAX для экстренной связи ребенка с родителями. Любые изменения должны учитывать безопасность, приватность и простоту детского интерфейса.

## Как предложить изменение

1. Создайте issue с описанием проблемы или предложения.
2. Для кода и документации создайте pull request в ветку `main`.
3. Опишите, какую задачу решает изменение.
4. Укажите, затрагивает ли изменение сценарии ребенка, родителя, хранение данных или отправку тревоги.
5. Приложите результат проверки, если изменение затрагивает код, Docker, CI/CD или пользовательские тексты.

## Проверки перед pull request

Запустите доступные проверки проекта:

```powershell
npm run validate
```

Если менялись Docker, зависимости или запуск приложения, дополнительно проверьте локальную сборку и старт сервиса.

## Требования к изменениям

- Не добавляйте реальные токены, пароли, ключи, `.env` и резервные копии базы данных.
- Не коммитьте локальные папки с презентациями, регистрационными документами, бэкапами и артефактами.
- Не публикуйте chat id, user id и другие эксплуатационные идентификаторы реальных пользователей.
- Тексты интерфейса должны быть понятными для детей и родителей.
- Изменения в тревожных сценариях должны минимизировать количество действий ребенка.
- Любые действия с продакшен-деплоем должны выполняться только по согласованному runbook и в правильном проекте Аралтыш.

## Версии и релизы

Версия хранится в `package.json`.

Для релиза используется схема:

```powershell
npm version <version> --no-git-tag-version
git commit -am "Release <version>"
git tag v<version>
git push origin main
git push origin v<version>
```

Публикация Docker/npm и деплой выполняются через настроенные workflow и Dokploy-проект Аралтыш.
